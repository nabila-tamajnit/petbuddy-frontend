## ✨ Fonctionnalités

- **Suivi multi-animaux** : Fiches détaillées par animal (espèce, race, poids, âge calculé automatiquement, numéro de puce...) avec photo personnalisée via Cloudinary.
- **Logs de bien-être** : Suivi quotidien de l'humeur, du niveau d'énergie, de l'appétit et des activités, avec une règle d'un log par jour par animal.
- **Carnet de santé** : Historique complet des visites vétérinaires, vaccins, vermifuges, pesées et notes libres, avec séparation à venir / passés.
- **Rappels intelligents** : Calendrier interactif par animal avec rappels de soins, statuts (en attente/fait/reporté) et alertes visuelles de retard.
- **Conseils personnalisés** : Tips quotidiens adaptés à l'espèce de chaque animal.
- **Gestion de compte** : Archivage / restauration des animaux, suppression de compte avec cascade complète des données.
- **Authentification JWT** : Connexion sécurisée, routes protégées, persistance de session.

---

## 💡 Compétences clés

- **Architecture en couches** : Services dédiés par ressource (animaux, rappels, suivis santé, bien-être) centralisant tous les appels Axios.
- **Tailwind CSS v4** : Design system custom via CSS variables (`--pb-*`), sans `tailwind.config.js`, avec utilitaires réutilisables.
- **UX soignée** : États vides personnalisés, filtrage intelligent des données passées/à venir, prompts contextuels selon l'activité de l'utilisateur.
- **Composants réutilisables** : Bibliothèque UI maison (Modal, Badge, Avatar, Spinner, EmptyState...) cohérente sur toute l'application.
- **Intégration Cloudinary** : Upload d'images optimisé pour les photos d'animaux.
